# ULIP Fund Comparison System

## Project Overview

This project analyzes and compares ULIP funds offered by multiple insurers using historical NAV data. The system evaluates funds based on:

- Return Metrics
- Risk Metrics
- Consistency Metrics

These metrics are combined into a final score, which is visualized through an interactive Streamlit dashboard.

# Data Collection Process

## HDFC Life NAV Data Collection

The historical NAV data for HDFC Life ULIP funds was collected through an automated Python-based solution that interacts directly with HDFC Life's backend APIs. This approach eliminated the need for manual data extraction from the website and ensured a faster, consistent, and scalable data collection process.

The automation covers the following HDFC Life products:

- HDFC Life Click 2 Wealth
- HDFC Life Click 2 Invest
- HDFC Life Sampoorn Nivesh Plus
- HDFC Life Smart Protect Plus

The required NAV history was collected for the period **31 July 2025 to 31 July 2026**.

### Workflow

The data collection process consists of three primary steps:

1. **Retrieve Available Funds**
   - Send an API request using the product ID to retrieve all associated ULIP funds.
   - The response contains the fund name and corresponding fund ID.

2. **Fetch Historical NAV Data**
   - Use the retrieved fund IDs to request historical NAV data for the specified date range.
   - The API returns the complete daily NAV history for each fund.

3. **Process and Store Data**
   - Convert the API response into Pandas DataFrames.
   - Append metadata such as product name, fund name, and fund ID.
   - Consolidate all datasets into a single Excel workbook and save it in the `nav_data_excel` directory.

## ICICI Prudential NAV Data Collection

The historical NAV data for ICICI Prudential ULIP funds was collected from two primary sources:

- **ICICI Prudential Official Website**
- **Moneycontrol**

Since the historical NAV values were embedded within interactive charts, the data was extracted using the browser's **Developer Console**.

### Data Extraction

The NAV values were obtained from the Highcharts JavaScript object using the following command:

```javascript
copy(
  Highcharts.charts[0].series[0].options.data
    .map(x => `${new Date(x[0]).toISOString().split('T')[0]},${x[1]}`)
    .join('\n')
);
```

The script extracts:

- Date (`YYYY-MM-DD`)
- NAV value

The extracted data is copied directly to the clipboard and saved as CSV files.

### Data Consolidation

A Python script was used to:

- Read all individual CSV files
- Standardize the data format
- Merge them into a single Excel workbook
- Store the final output in the `nav_data_excel` directory

# Metrics

## Return Metrics

### Objective

The Return Metrics module calculates the historical returns of each ULIP fund and generates a standardized **Return Score** for comparison within the same investment category.

The module computes:

- 1-Month Return
- 3-Month Return
- 6-Month Return
- 1-Year Return
- Average Return
- Return Rank
- Return Score

The output is generated separately for each insurer and stored in the `algorithm/output_result/return_metrics` directory.

---

### Methodology

#### 1. Data Loading

The script reads the consolidated `Nav Table.xlsx` workbook, where each insurer's NAV data is stored in a separate worksheet. The **Lookup** sheet is used to map funds to their respective categories.

#### 2. Fund-wise Processing

The NAV data is grouped using the **SFIN (Segregated Fund Identification Number)** so that each fund is processed independently. All NAV records are sorted chronologically before performing any calculations.

#### 3. Return Calculation

The following return periods are calculated:

- 1-Month Return
- 3-Month Return
- 6-Month Return
- 1-Year Return

For each period:

- The latest available NAV is identified.
- The corresponding historical NAV is selected based on the required look-back period.
- If NAV data is unavailable on the exact target date, the nearest available NAV within a **10-day tolerance** is used.
- If no valid NAV exists within the tolerance window, the return is left unavailable.

The return is calculated as:

```text
Return (%) = ((Current NAV - Previous NAV) / Previous NAV) × 100
```

#### 4. Average Return

The **Average Return** is calculated as the arithmetic mean of the available return periods:

- 1-Month Return
- 3-Month Return
- 6-Month Return
- 1-Year Return

This value is used as the primary metric for ranking funds.

#### 5. Category Mapping

Each fund is mapped to its investment category using the **Lookup** table.

Detailed categories are grouped into broader asset classes:

- Equity
- Hybrid
- Debt

This ensures that funds are compared only with similar investment types.

#### 6. Return Ranking

Funds are ranked within each **Insurer** and **Broad Category** based on their Average Return.

- Higher Average Return receives a better rank.
- Dense ranking is used, allowing funds with equal returns to share the same rank.

#### 7. Return Score

The category-wise ranks are converted into a normalized **Return Score** ranging from **0 to 100** using the formula:

```text
Return Score = ((Total Funds - Rank) / (Total Funds - 1)) × 100
```

Where:

- **100** indicates the highest-performing fund within the category.
- **0** indicates the lowest-performing fund.
- If a category contains only one fund, a score of **100** is assigned.

- ## Risk Metrics

The Risk Metrics module analyzes the historical NAV data of each ULIP fund to evaluate its risk profile. It calculates key statistical measures related to fund volatility and downside risk and generates both detailed daily-level data and fund-level summary statistics.

---

### Calculated Metrics

#### Daily Return (%)
- Calculates the percentage change in NAV compared to the previous trading day.
- Stored in the insurer-wise `Daily_Returns.xlsx` files.

#### Daily Volatility (%)
- Measures the standard deviation of daily returns.
- Indicates the day-to-day fluctuation in fund performance.

#### Annualized Volatility (%)
- Calculated by multiplying Daily Volatility by **√250**.
- Represents the expected annual volatility of the fund.

#### Previous Peak NAV
- Tracks the highest NAV achieved by the fund up to each trading day.

#### Drawdown (%)
- Measures the percentage decline in NAV from the previous peak NAV.
- Indicates the extent of losses experienced by the fund.

#### Maximum Drawdown (%)
- Represents the largest observed decline from a peak NAV during the available historical period.

#### Downside Deviation (%)
- Measures the standard deviation of only the negative daily returns.
- Focuses specifically on downside risk.

#### Annualized Downside Deviation (%)
- Calculated by multiplying Downside Deviation by **√250**.
- Represents the annualized downside risk of the fund.

## Consistency Metrics

### Objective

The Consistency Metrics module evaluates the stability and reliability of a ULIP fund's performance over time. Unlike return metrics, which measure overall performance, this module focuses on how consistently a fund delivers positive returns and maintains competitive rankings.

---

### Methodology

#### 1. Data Preparation

The consolidated NAV data is loaded and standardized across all insurers. Daily NAV values are then converted into **month-end NAVs** to create a consistent monthly time series for each fund.

#### 2. Monthly Performance Calculation

The algorithm calculates:

- Monthly Returns based on consecutive month-end NAVs.
- Rolling 3-Month Returns to evaluate medium-term performance consistency.

#### 3. Monthly Ranking

Funds are ranked each month within their respective insurer based on monthly returns. These rankings are used to assess the consistency of a fund's relative performance over time.

#### 4. Consistency Metrics

The following metrics are calculated for every fund:

- **Positive Month Ratio** – Percentage of months with positive returns.
- **Rolling Return Consistency** – Percentage of positive rolling 3-month return periods.
- **Average Rank** – Average monthly ranking throughout the evaluation period.
- **Top Half Ratio** – Percentage of months in which the fund ranked within the top 50% of funds.

#### 5. Consistency Score

A weighted score is calculated using the following components:

| Metric | Weight |
|--------|--------:|
| Positive Month Ratio | 40% |
| Rolling Return Consistency | 40% |
| Top Half Ratio | 20% |

Funds with higher scores are considered more consistent performers.

---

## Output

The algorithm generates an Excel workbook with two worksheets.

### 1. Fund Summary

Contains the final consistency metrics for each fund, including:

- Positive Month Ratio
- Rolling Return Consistency
- Average Rank
- Top Half Ratio
- Consistency Score
- Status

### 2. Monthly Calculations

Contains the intermediate calculations used to derive the final metrics, including:

- Month-End NAV
- Monthly Return
- Rolling 3-Month Return
- Monthly Rank

---

## Notes

- The first month's **Monthly Return** is blank because there is no previous month's NAV for comparison.
- The initial **Rolling 3-Month Returns** are blank due to insufficient historical data.
- Funds with limited NAV history are marked as **Insufficient History** and are excluded from consistency scoring to ensure fair and reliable comparisons.

## Category Comparison Module

### Objective

The Category Comparison Module combines the outputs of the **Return Metrics**, **Risk Metrics**, and **Consistency Metrics** modules to provide an overall performance evaluation of ULIP funds. Funds are compared only with other funds belonging to the same broad investment category within the same insurer, ensuring fair and meaningful comparisons.

---

### Methodology

#### 1. Data Loading

The module automatically loads the outputs generated by the previous modules:

- Return Metrics
- Risk Metrics
- Consistency Metrics

It also loads the **Lookup** sheet from the NAV master file to retrieve the investment category for each fund.

#### 2. Data Standardization

Fund and insurer names are standardized across all datasets before merging. This resolves naming inconsistencies (e.g., `TATA AIA` and `Tata AIA`) and ensures accurate data integration.

#### 3. Category Mapping

Detailed investment categories are grouped into broader asset classes:

- Equity
- Hybrid
- Debt

This enables meaningful comparisons by ranking funds within similar investment categories.

#### 4. Data Integration

The Return, Risk, and Consistency datasets are merged using **Insurer** and **Fund Name** as common keys. The merged dataset includes:

- Return Score
- Risk Score
- Consistency Score
- Fund Category

#### 5. Final Score Calculation

A composite **Final Score** is calculated using the following weighted average:

| Metric | Weight |
|--------|--------:|
| Return Score | 40% |
| Risk Score | 30% |
| Consistency Score | 30% |

#### 6. Category Ranking

Funds are ranked within each **Insurer** and **Broad Category** based on their Final Score using **dense ranking**, where the highest-scoring fund receives **Rank 1**.

---

## Output

The module generates `Category_Comparison.xlsx`, containing:

- Insurer
- Fund Name
- Category
- Broad Category
- Return Score
- Risk Score
- Consistency Score
- Final Score
- Category Rank

---

## Special Cases

- **Insufficient Historical Data:** Funds with inadequate NAV history are excluded from final scoring and ranking to ensure reliable comparisons.
- **Category Standardization:** Detailed investment categories are consolidated into broader asset classes to facilitate meaningful peer-group analysis.

# Dashboard

### Objective

A web-based dashboard was developed using **Streamlit** to provide an interactive platform for comparing ULIP funds across different insurers. The dashboard presents the results of the Return, Risk, and Consistency analyses in a simple and user-friendly interface, enabling users to filter, compare, and evaluate funds efficiently.

**Dashboard URL:**  
https://ulip-nav-dashboard-wrrtjdldiecregz53feush.streamlit.app/

---

## Features

### 1. Data Loading

The dashboard reads the `Category_Comparison.xlsx` file, which contains the consolidated Return, Risk, Consistency, and Final Scores for all funds.

### 2. Interactive Filters

Users can filter the displayed data based on:

- Insurer
- Broad Category
- Fund Name

### 3. Dashboard Overview

The dashboard displays key summary metrics, including:

- Total Number of Funds
- Average Return Score
- Average Risk Score
- Average Consistency Score

### 4. Fund Rankings

A ranking table displays the filtered funds in descending order of **Final Score**, along with their Return, Risk, and Consistency Scores.

### 5. Performance Visualizations

The dashboard provides interactive charts, including:

- Top 10 Funds based on Final Score
- Risk vs. Return Scatter Plot

These visualizations help users compare fund performance and understand the relationship between risk and returns.

### 6. Fund Details

Users can view detailed information for an individual fund, including:

- Final Score
- Return Score
- Risk Score
- Consistency Score
- Category
- Category Rank
- Overall Rating (Strong, Good, Average, Weak/Review, or Insufficient Data)

### 7. Download Option

The final `Category_Comparison.xlsx` dataset can be downloaded directly from the dashboard for further analysis and reporting.
